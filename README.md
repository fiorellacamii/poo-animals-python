# poo-animals-python

Este proyecto es un ejercicio de Programación Orientada a Objetos en Python, creado como tarea para prácticas universitarias. Se desarrolla alrededor de diferentes animales, aplicando conceptos de POO como herencia, clases, métodos y atributos.

## Descripción

El proyecto contiene dos archivos principales:

- `poo con menu.py`: Permite al usuario interactuar por consola con un menú. Puedes seleccionar el animal (vaca, gato, perro, gallina) y la acción que deseas realizar (comer, caminar, hacer sonido, dormir, cumplir años, etc.).
- `poo sin menu.py`: Es una versión donde debes ejecutar las funciones directamente escribiendo el código, sin interfaz de menú.

## Animales disponibles

- Vaca
- Gato
- Perro
- Gallina

Cada animal hereda de una clase padre y tiene sus propios métodos y atributos.

## Uso

### 1. Clonar el repositorio

```bash
git clone https://github.com/fiorellacamii/poo-animals-python.git
cd poo-animals-python
```

### 2. Ejecutar con menú

```bash
python "poo con menu.py"
```

Sigue las instrucciones en pantalla para seleccionar un animal y la acción que quieres que realice.

#### Ejemplo de salida:

```
--- Selecciona un animal ---
1. Vaca
2. Gato
3. Perro
4. Gallina
Opción: 2

--- Acciones para Gato ---
1. Comer
2. Caminar
3. Hacer sonido
Opción: 3

El gato maúlla: "¡Miau, miau!"
```

### 3. Ejecutar sin menú

```bash
python "poo sin menu.py"
```

En este caso, puedes modificar el archivo para probar directamente las funciones de los animales.
