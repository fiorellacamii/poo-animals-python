# poo-animals-python
Se trata de un codigo escrito por una chica gamer, que estaba haciendo su tarea de programaciony hizo un codigo relacionado a animales en python

Ambos codigos son "Basicos" Trata de Programacion Orientada a Objetos, yo lo realice basado en animales, tal como vaca, gato, perro y gallina, Tiene Su clase padre con sus atributos y metodos, y sus clases hijas, ademas tiene poliformismo haciendo que cada animal se comporte de manera diferente dependiendo de la accion que se tome.

Uno tiene menu y el otro no, en el que tiene menu nos pedira seleccionar un animal y segun el animal que seleccionemos nos pedira si deseamos movernos, jugar, comer, dormir, cumplir años, hacer sonido o realizar una accion especial que tendra cada animal
